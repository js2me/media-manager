# Фототека

Настольное приложение для Ubuntu. Показывает доступные по USB фото и видео с Android, iPhone, iPad и внешних накопителей. В боковой панели можно выбрать устройство, папку и тип файла. Нажмите миниатюру, чтобы открыть снимок или видео.

## Установка из релиза

Для Ubuntu 24.04 x86_64 скачайте пакет из [последнего релиза](https://github.com/js2me/media-manager/releases/latest). Установите deb командой `sudo apt install ./media-manager_*.deb` и откройте «Фототеку» из меню приложений.

Для AppImage установите системные компоненты Ubuntu из команды ниже, дайте файлу право на запуск (`chmod +x *.AppImage`) и откройте его. Оба пакета содержат собранный интерфейс и используют системные Python, GTK, WebKitGTK и драйверы устройств. Node.js нужен только для сборки из исходников.

Каждый push в `main` запускает сборку, тесты и публикацию обоих пакетов с тегом `v<версия>-build.<номер>`. Скачанные файлы можно проверить командой `sha256sum -c SHA256SUMS.txt` в каталоге с обоими пакетами.

## Запуск из исходников

Нужны Node.js 22.12+ и графический сеанс Ubuntu. Установите зависимости и запустите в каталоге проекта:

```sh
npm ci
npm start
```

На этом компьютере системные компоненты уже установлены. Для другой установки Ubuntu с GTK 3 и WebKitGTK 4.1:

```sh
sudo apt install python3-gi gir1.2-gtk-3.0 gir1.2-webkit2-4.1 gvfs-backends gvfs-fuse usbmuxd ffmpeg libheif-examples gstreamer1.0-libav gstreamer1.0-plugins-good
```

Разблокируйте устройство. На Android выберите передачу файлов или фото, на iPhone и iPad подтвердите доверие к компьютеру. Фототека обнаруживает изменения подключения автоматически. Чтобы перечитать содержимое подключённого устройства, нажмите «Обновить».

Внешний диск, флешка или карта памяти появятся в боковой панели после монтирования в Ubuntu. Выберите накопитель по названию, чтобы открыть его медиатеку.

На телефоне папки соответствуют структуре, которую устройство предоставляет через MTP, PTP или AFC. Облачные оригиналы должны быть загружены на устройство. Воспроизведение видео зависит от установленных кодеков GStreamer.

## Перенос медиатеки

Выберите телефон в боковой панели, откройте «Перенос медиатеки» и укажите существующую папку компьютера или подключённый диск. По умолчанию выбраны все папки устройства. Снимите «Все папки» и отметьте нужные каталоги. Счётчик покажет число выбранных файлов. Выбор относится к файлам непосредственно внутри отмеченных папок.

Доступны исходная структура, группировка по году и месяцу изменения и группировка по типу (Photos / Videos). Внутри каждой группы сохраняется исходный путь. Файлы без известной даты попадают в Unknown-date. При запуске в каталоге назначения создаётся `.photo-library-transfer.json` с выбранными папками, группировкой и режимом удаления. При следующем выборе этого каталога приложение восстановит настройки. Удаление по-прежнему требует подтверждения.

По умолчанию оригиналы остаются на устройстве. Для освобождения места включите удаление и подтвердите его перед запуском. Каждый файл удаляется только после проверки копии по SHA-256. Если два файла по одному пути различаются, операция останавливается. После отмены или сбоя можно повторно выбрать ту же папку — приложение проверит уже записанные копии.

## Устройство проекта

SolidJS-интерфейс организован по слоям FSD в `src`. В `pages/library` представление использует `mobx-view-model-solid`, а модель представления управляет состоянием MobX, сканированием и выбором файлов. `mobx-web-api` отслеживает видимость окна для обновления списка устройств.

Адаптер Ubuntu в `desktop/devices.py` использует GIO/GVfs. При отключённом аппаратном ускорении WebKit приложение использует отдельное окно установленного Chrome или Chromium. В остальных случаях интерфейс открывается в WebKit. Оболочка GTK запускает локальный HTTP-сервер на случайном порту loopback с отдельным адресом на каждый запуск. Интерфейс обращается к этому API независимо от ОС. Сейчас реализована платформа Ubuntu.
